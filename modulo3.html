A Python avanzado

Los dunder methods en Python: qué hacen realmente __init__, __str__ y __len__

"Dunder" viene de double underscore. Son métodos especiales que Python llama automáticamente en momentos concretos, permitiendo que tus propios objetos se comporten como los tipos nativos.

MétodoSe dispara cuando…
__init__se crea una nueva instancia (el "constructor")
__str__se hace print(objeto) o str(objeto)
__len__se hace len(objeto)

Frameworks/librerías front-end

Aunque el foco del bootcamp es datos y backend, es útil reconocer el panorama front-end (React, Vue, Svelte) para entender cómo consumen las APIs que se construyen del lado de Python, y para poder armar demos o dashboards simples sin depender siempre de otro equipo.

Regex (Expresiones Regulares): el superpoder de la búsqueda de patrones en texto

Un mini-lenguaje para describir patrones de texto: validar un email, extraer todos los números de un documento, limpiar espacios repetidos. Una vez interiorizada la sintaxis básica, resuelve en una línea tareas que a mano tomarían decenas.

import re
re.findall(r"\d+", "Factura 2024-035, total 128")   # ['2024', '035', '128']

Librería NumPy: Arrays y operaciones matemáticas

Los arrays de NumPy almacenan datos numéricos de forma contigua en memoria y permiten operaciones vectorizadas (aplicar una operación a todo el array de una vez), lo que las hace órdenes de magnitud más rápidas que un loop en Python puro sobre listas.

NumPy Broadcasting: cómo operar matrices de diferentes formas sin loops

Broadcasting permite operar un array pequeño contra uno más grande "estirando" virtualmente el pequeño para que coincidan las formas, sin copiar datos de más ni escribir loops explícitos.

Markdown avanzado: tablas, diagramas Mermaid y fórmulas LaTeX en tu documentación

Markdown va mucho más allá de negritas y títulos: soporta tablas para comparar opciones, diagramas Mermaid para flujos y arquitecturas (```mermaid), y fórmulas matemáticas en LaTeX ($$...$$) — todo texto plano, versionable en Git.

\(E = mc^2\)

Esa línea se escribe simplemente como $$E = mc^2$$ en el Markdown.

Docker Volumes: persistencia de datos (que no se borre tu BBDD al apagar el contenedor)

Un contenedor Docker es efímero por diseño: al eliminarlo, todo lo que escribió en su sistema de archivos interno desaparece. Un volumen conecta una carpeta del contenedor con almacenamiento real fuera de él (en el host o gestionado por Docker), para que datos como una base de datos sobrevivan a reinicios y actualizaciones del contenedor.

Visualización de datos faltantes con missingno

La librería missingno permite ver de un vistazo dónde y cómo se concentran los valores nulos de un DataFrame (matriz, heatmap de correlación entre nulos, dendrograma), algo mucho más difícil de detectar solo con df.isnull().sum().

DVC (Data Version Control) - Introducción

Git versiona bien código, pero no datasets grandes ni modelos pesados. DVC extiende esa misma lógica de versionado (commits, branches) a archivos de datos y modelos, guardando solo punteros ligeros en Git mientras los archivos reales viven en almacenamiento externo (S3, Google Drive, etc.).

Linters modernos: Ruff vs Black

Black

Formateador "sin opiniones que discutir": reescribe el código a un único estilo consistente automáticamente.

Ruff

Linter (y cada vez más, también formateador) escrito en Rust, extremadamente rápido, que detecta errores, imports sin usar y problemas de estilo, reemplazando varias herramientas antiguas (flake8, isort) a la vez.

Git Stash & Cherry-pick: cómo guardar cambios temporales o "robar" commits específicos

git stash

Guarda temporalmente los cambios sin commitear para poder cambiar de rama con el árbol de trabajo limpio, y recuperarlos después con git stash pop.

git cherry-pick

Toma un commit específico de otra rama y lo aplica sobre la rama actual, sin traer el resto del historial de esa rama.

C Estadística aplicada

Test de hipótesis en Python (T-test)

scipy.stats

Un T-test evalúa si la diferencia observada entre dos grupos (por ejemplo, conversión con y sin un cambio de diseño) es lo bastante grande como para no ser explicable solo por azar, dado el tamaño de muestra y su variabilidad.

Cuanto menos se solapan las dos distribuciones, más probable es que la diferencia entre grupos sea real (y no ruido).

La paradoja de Simpson (Estadística interpretativa / Caso de estudio)

Ocurre cuando una tendencia aparece en varios grupos por separado, pero se revierte o desaparece al combinar esos grupos en uno solo — normalmente porque una tercera variable oculta (un factor de confusión) afecta de forma distinta a cada grupo.

Historia del sesgo: Caso real I y repercusiones

Los casos históricos de algoritmos que amplificaron sesgos existentes en los datos (en contratación, crédito o justicia predictiva) muestran que un modelo "matemáticamente correcto" puede seguir siendo injusto si los datos de entrenamiento ya reflejaban desigualdades previas.

Historia del sesgo: Caso real II y repercusiones

Un segundo caso refuerza la misma lección desde otro ángulo: la responsabilidad de auditar el sesgo no termina al lanzar el modelo — requiere monitoreo continuo, porque los patrones de los datos (y del mundo real que representan) cambian con el tiempo.

D Data Storytelling y visualización

Data Storytelling: teoría del color, composición y cómo narrar una historia con datos

Un buen gráfico no solo muestra números correctos: guía la mirada hacia el mensaje principal. Eso implica elegir qué resaltar con color (y qué dejar en gris), ordenar la composición para que el ojo siga un recorrido lógico, y acompañar el dato con una narrativa clara de qué significa y qué hacer al respecto.

Gestalt en Visualización: Principios psicológicos de agrupación visual para dashboards

ProximidadSimilitud ContinuidadCierre

El cerebro agrupa elementos visuales automáticamente según estos principios, aunque nadie se lo indique explícitamente. Un dashboard bien diseñado aprovecha esto a propósito: elementos relacionados se colocan cerca (proximidad) y con estilos similares (similitud), para que la relación entre ellos sea obvia sin necesidad de leer etiquetas.

Colores en Dataviz: Paletas secuenciales vs divergentes vs categóricas

Secuencial: para valores de bajo a alto. Divergente: para valores con un punto medio significativo (0, promedio). Categórica: para categorías sin orden intrínseco.

E Dashboards con Streamlit

Desarrollo de dashboards con Streamlit (estructura y widgets básicos)

Streamlit convierte un script de Python normal en una app web interactiva, sin escribir HTML/CSS/JS. Cada widget (st.slider, st.selectbox, st.file_uploader) es una línea de código que automáticamente añade un control interactivo a la página.

Streamlit II: Callbacks, session state, despliegue (Streamlit Cloud)

Streamlit re-ejecuta todo el script de arriba a abajo cada vez que el usuario interactúa con un widget. st.session_state es la forma de conservar información entre esas re-ejecuciones (por ejemplo, un contador o datos ya cargados), y los callbacks permiten reaccionar a un cambio de widget antes de que se vuelva a dibujar la página. Streamlit Cloud permite publicar la app gratis directo desde un repositorio de GitHub.
